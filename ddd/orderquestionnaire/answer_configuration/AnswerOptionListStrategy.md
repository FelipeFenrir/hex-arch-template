É a estratégia de configuração de resposta em formato de lista de opções.

Campos:

- answerOptions: Mapa de label e valor para cada opção de resposta.
- customErrorMessage: Mensagem de erro customizada.

Exemplo:

    answerOptions:
        { value: "sim", label: "Sim" },  
        { value: "nao", label: "Nao" }   
    customErrorMessage: null
