'questionnaire' representa um questionário que pode ser usado para obter respostas em uma jornada de venda de algum produto com o objetivo de coletar dados para verificações e cálculos posteriores.

Todo questionnaire é composto por:

- id: Código Identificador em formato sneak_case (ex: questionnaire_seguro_auto).
- channel_distribution_id: 
- journey_distribution_id: 
- description: Descreve o objetivo do questionário.
- questions_count: Soma de questões contidas no questionário.
- active: Identifica o status do registro ([[Status de Parametrização]]).
- [[created_by]]: Dados mínimos do usuário que criou o registro.
- created_at: Data e hora de criação do registro.
- [[update_by]]: Dados mínimos do usuário que atualizou o registro.
- updated_at: Data e hora de atualização do registro.
